# 3-minute screen recording script (one continuous take, speak in your own words)

Open the deployed app first. Keep the Import & replay page ready. Practise once; aim for 2:45.

**0:00 - 0:10  Intro (say):** "This is my Revenue Intelligence Inbox. It helps a sales manager see what needs a decision from 44 selected records."

**0:10 - 0:40  Useful manager workflow (Dashboard):**
- Import & replay -> click *1. Import initial*. Say: "44 unique records, 17 usable texts."
- Dashboard: point at *Need a person* and *Usable text coverage 17/44*. Pick source type = call.
- Explain ONE metric: "Coverage is usable texts divided by selected records in the same filter. Missing text does not mean the call did not happen."
- Review queue: show C10 and say why (label says follow_up, but the contact declined a follow-up call).

**0:40 - 1:25  Difficult routing decision (Inbox & evidence):**
- Open M04. Say: "Existing customer, card programme closing, wants credit not prepaid. I gave it two routes: customer follow-up and deal next steps, because it is a retention risk and a possible expansion."
- Click the evidence lines (turn 4, 10, 11) and show the green checks. Say: "Every claim points to a numbered turn that is checked against the source."
- Say what is NOT established: "We don't know the bank-card feed is feasible."

**1:25 - 2:45  Duplicate / update test:**
1. Import & replay -> *2. Import initial again (shuffled)*. Say: "Still 44, log shows 0 added, 44 ignored."
2. Inbox -> open M07. It has no text (awaiting later batch). Set route manually to *Internal / vendor note*, note "product bug escalation", Save. Say: "Manual decision saved; the automated suggestion is kept separate."
3. Import & replay -> *3. Import update (revision 2)*. Say: "Still 44 records, usable texts now 18, M07 is revision 2."
4. Click *Re-import initial (old revision)*. Say: "Old revision is ignored."
5. Inbox -> M07: show the new text and that the route is still manual, analysis is current. Press the browser refresh (F5) and show it is unchanged. Say: "The manual route survived the update, the old batch and a refresh."

**2:45 - 3:00  Close:** Export page -> *Generate export now*, show the manifest columns manual_override and output_paths. "Exports and manifest are rebuilt from current state."
